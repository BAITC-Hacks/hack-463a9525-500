# Схема решения

```mermaid
flowchart LR
    A[Обезличенные parquet<br/>nodes · edges · transactions] --> B[Проверка схемы<br/>и сверка сумм]
    B --> C[Направленный граф<br/>степени · PageRank · посредничество<br/>временные паттерны · компоненты]
    C --> E[Louvain на<br/>ненаправленной проекции]
    C --> D[Непрерывные оценки ролей<br/>и отдельный приоритет]
    E --> D
    D --> F[outputs: три CSV<br/>и dashboard.json]
    F --> G[FastAPI: граф · узел · поиск<br/>кластеры · пути · AI Analyst]
    G --> H[Next.js: обзор · граф<br/>приоритеты · сообщества · методика]
```

Ненаправленная проекция используется только для поиска сообществ. Роли, пути и связи сохраняют направление перевода. API и UI читают рассчитанный снимок; ответы AI Analyst ссылаются на измеренные GID и признаки.
